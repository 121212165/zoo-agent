# 南京红山森林动物园 · 智能陪逛 Agent 前端设计文档

## 1. 项目概述

红山陪逛是一个**移动端优先**的智能陪逛助手，模拟小程序/手机应用的体验，为游客提供红山动物园的智能导览、路线规划、动物百科和园区地图功能。

- **设计定位**：懂红山 · 懂动物 · 更懂你的陪逛向导
- **目标用户**：南京红山森林动物园的游客（亲子家庭、年轻人、老人）
- **UI 风格**：自然、温暖、绿色、圆润、卡片式

```
index.html          ← 主页面结构
```

```
└── 弹窗层 (modal)

```

## 4. 组件规范

### 4.1 手机外壳 (phone-frame)

- 最大宽度：`400px`
- 高度：`85vh`（最高 850px，最低 600px）
- 圆角：`40px`
- 背景：`#F5F7FA`
- 投影：`0 8px 32px rgba(0,0,0,0.15)`
- 居中显示在页面中

### 4.2 顶部导航栏 (app-header)

- 高度：`56px`（padding: 20px 20px 16px）
- 背景：`linear-gradient(135deg, #2D7D46 → #4CAF50)`
- 布局：`flex, space-between`
- Logo 区域：`🐾` 图标（36px）+ 文字标题
- 右侧：关于按钮（圆形 `40px`，半透明白底）

### 4.3 标签栏 (tab-nav)

- 背景：白色
- 底部：`1px solid #E8E8E8` 分隔线
- 4 个标签等分（flex: 1）
- 每个标签：SVG 图标（22px）+ 文字（11px）
- 激活态：文字颜色变绿，底部 3px 绿色指示条

### 4.4 聊天界面

#### 4.4.1 消息列表
- 间距：`16px` padding，消息之间 `12px` gap
- 用户消息：右对齐（flex-direction: row-reverse），紫色气泡，白色文字
- AI 消息：左对齐，白色气泡，深色文字
- 头像：圆形 `36px`，AI 为绿色渐变，用户为紫色渐变
- 气泡圆角：`24px`，内边距 `12px 16px`
- 文字大小：`14px`，行高 `1.7`

#### 4.4.2 欢迎消息
- 气泡背景：`linear-gradient(135deg, #667eea → #764ba2)`（紫色渐变）
- 白色文字
- 快捷问题按钮：半透明白色背景，圆角 `24px`，`12px` 文字

#### 4.4.3 输入区域
- 背景：白色，顶部 `1px solid #E8E8E8` 分隔线
- 输入框：圆角 `24px`，`14px` 文字，聚焦时绿色边框
- 语音按钮：绿色圆形，激活时变红色并脉冲动画
- 发送按钮：绿色圆形，无输入时 `opacity: 0.4` 不可点击

#### 4.4.4 语音输入覆盖层
- 全屏半透明黑色（`rgba(0,0,0,0.7)`）+ 毛玻璃效果
- 声波动画：10 条竖条，高度 18~70px，交替动画
- 提示文字：`18px` 白色
- 取消按钮：圆角 `24px`，半透明白色边框

### 4.5 地图界面

- 画布：`600 × 450`，自适应缩放
- 背景：绿色渐变（`#E8F5E9 → #C8E6C9`）

#### 4.5.3 设施切换

#### 4.5.4 场馆卡片

## 5. 交互行为

### 5.1 页面切换
- 点击标签栏切换 4 个 Tab
- 激活标签底部显示绿色指示条
- 内容区切换显示对应 tab-content

### 5.2 聊天交互
- 用户输入问题 → 按回车或点击发送按钮
- 输入框空时发送按钮灰色不可点击
- 消息发送后清空输入框
- 显示打字动画（3 个圆点跳动）
- 消息支持 Markdown 粗体语法（`**粗体**`）
- 自动滚动到底部
- 语音识别：点击语音按钮 → 显示声波覆盖层 → 识别中文 → 自动发送

### 5.3 地图交互
- 点击场馆标记 → 底部弹出场馆卡片
- 点击设施标记 → 底部弹出设施信息
- 点击设施切换按钮 → 过滤显示对应类型设施
- 场馆卡片中的"听讲解"按钮 → 跳转到聊天 Tab 并发送讲解请求

### 5.4 路线规划交互
- 点击选项按钮切换状态（激活/取消）
- 点击"生成我的专属路线" → 调用 API → 显示路线结果
- 路线结果包含站点列表和统计信息
- 自动滚动到结果区域

### 5.5 动物列表交互
- 点击筛选按钮过滤动物列表
- 点击动物卡片 → 弹出动物详情弹窗
- 弹窗中"和我聊聊它" → 关闭弹窗，跳转到聊天 Tab 并发送查询

### 5.6 语音播报
- AI 回复自动进行语音播报
- 使用 Web Speech API（`SpeechSynthesis`）
- 自动过滤 emoji 和 Markdown 符号

## 7. 动画系统

| 动画 | 触发 | 时长 | 描述 |
|------|------|------|------|
| `fadeIn` | 新消息出现 | 0.3s | 从下往上淡入 |
| `typing` | 正在输入 | 1.4s | 3 个圆点交替缩放 |
| `pulse` | 语音录制 | 1.5s | 红色按钮脉冲光晕 |
| `wave` | 语音声波 | 0.8s | 10 条竖条交替缩放 |
| `slideUp` | 弹窗出现 | 0.3s | 从下往上滑入 |
| 场馆卡片弹出 | 点击场馆 | 0.3s | translateY(100%) → 0 |
| 卡片 hover | 鼠标悬停 | 0.2s | 上移 2px，阴影加深 |

## 8. 核心 API 接口

| 接口 | 方法 | 用途 |
|------|------|------|
| `/api/welcome` | GET | 获取欢迎语和快捷问题 |
| `/api/info` | GET | 获取动物园基本信息 |
| `/api/map` | GET | 获取地图数据（场馆+设施坐标） |
| `/api/animals` | GET | 获取动物列表 |
| `/api/animals/:id` | GET | 获取单个动物详情 |
| `/api/chat` | POST | AI 对话 |
| `/api/route/plan` | POST | 路线规划 |
| `/api/active-animals?time=` | GET | 获取当前活跃动物 |
| `/api/nearby-facilities` | POST | 查询附近设施 |
| `/api/venues` | GET | 获取场馆列表 |

## 10. 数据可视化

### 10.1 地图标记系统

场馆标记使用 SVG 圆形 + emoji 组合，区分三个等级：

```
T0 必看：橙色圆形 (#FF9800) + 场馆名称标签
T1 推荐：绿色圆形 (#4CAF50) + 场馆名称标签
T2 可选：蓝色圆形 (#2196F3) + 场馆名称标签
```

设施标记使用 SVG 圆角矩形 + emoji，类型包括：

| 类型 | 标记 | 颜色 |
|------|------|------|
| 卫生间 | 🚻 | `#9E9E9E` |
| 餐厅 | 🍴 | `#9E9E9E` |
| 休息区 | 🪑 | `#9E9E9E` |
| 入口 | 🚪 | `#E91E63`（粉色） |
| 直饮水 | 💧 | `#9E9E9E` |

### 10.2 动物卡片

卡片使用 emoji 作为视觉主力，配合等级徽章和场馆名，形成快速识别系统。

## 11. 语音交互

- **语音识别**：Web Speech API（`SpeechRecognition`），中文普通话
- **语音合成**：`SpeechSynthesis`，中文语音，1.0 倍速
- 过滤 emoji（Unicode 范围 `U+1F300-U+1F9FF`、`U+2600-U+26FF`、`U+2700-U+27BF`）和 Markdown 符号
- 短文本（< 5 字符）不播报
